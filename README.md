# Kotlin Practice

Мои упражнения по Kotlin на пути к Android-разработке. Здесь лежат решения задач и конспекты.

## Структура

- `01-lists/`: списки и массивы (сумма, максимум, самая длинная строка, разворот, удаление дубликатов)
- `02-loops/`: циклы (таблица умножения, FizzBuzz)
- `03-classes/`: классы, `data class`, `BankAccount` с инкапсуляцией
- `04-lambdas/`: `filter`, `map`, функции с лямбдой
- `05-null-safety/`: `?`, `?.`, `?:`
- `06-interfaces-inheritance/`: интерфейсы и `open class`
- `07-enum-sealed/`: `enum`, `sealed class`, `when`
- `notes.md`: мои конспекты

## План

Октябрь: Kotlin. Ноябрь: Android и Jetpack Compose. Дальше: корутины, сеть, Room, архитектура, проекты для портфолио.

## Как запускать

Каждый файл содержит функцию `main()`. Запускай в Android Studio (IntelliJ) или на play.kotlinlang.org.
