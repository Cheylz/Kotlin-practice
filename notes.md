# Заметки по Kotlin

## 1. Списки и массивы

- `Array`: фиксированный размер, `arrayOf(1, 2, 3)`.
- `List`: нельзя менять, `listOf(...)`. `MutableList`: можно добавлять и удалять, `mutableListOf(...)`.
- В Android почти всегда используют списки, а не массивы.

```kotlin
val numbers = listOf(1, 2, 3)
val result = mutableListOf<Int>()
result.add(4)
```

**Где я ошибался:** в `for (n in numbers)` переменная `n` уже сам элемент, поэтому `numbers[n]` писать не нужно.

## 2. Циклы и условия

- `for (n in numbers)`: по значениям.
- `for (i in numbers.indices)`: по индексам (тогда `numbers[i]`).
- `for ((i, n) in numbers.withIndex())`: и индекс, и значение.
- Диапазоны: `1..5` (5 включено), `1 until 5` (5 нет), `5 downTo 1`, `1..10 step 2`.
- Цепочка `if / else if / else`: срабатывает только первая подошедшая ветка, поэтому самое узкое условие проверяют первым (FizzBuzz: сначала «кратно и 3, и 5»).

## 3. `in` и `!in`

- `x in list`: есть ли элемент в коллекции (`true` или `false`).
- `x !in list`: элемента там нет.
- Это короткая запись для `list.contains(x)`.

```kotlin
if (number !in result) result.add(number)  // удаление дубликатов
```

## 4. Классы

- `class Book(val title: String, val year: Int)`: поля объявляются прямо в скобках.
- `val`: поле нельзя менять, `var`: можно.
- Если переменная не переназначается, пиши `val`.
- Обычный `class`: `==` сравнивает объекты («тот же самый?»), а `println` показывает `Book@123abc`.
- `data class`: `==` сравнивает содержимое полей, `println` выводит читаемый текст, есть `copy(year = 2000)`.
- `data class` нужен для классов, которые просто хранят данные.

## 5. Инкапсуляция

- `private set`: читать поле можно снаружи, менять только через методы класса.
- Всегда спрашивай себя: какие «неудобные» значения могут прийти (0, отрицательные числа)? Проверяй их в методах.

```kotlin
var balance: Int = balance
    private set
```

## 6. Лямбды, `filter` и `map`

- Лямбда: маленькая безымянная функция `{ it * 2 }`, где `it` это текущий элемент.
- `filter { ... }`: оставить подходящие элементы.
- `map { ... }`: преобразовать каждый элемент.
- Цепочка читается слева направо: `numbers.filter { it % 2 == 0 }.map { it * it }`.
- Если лямбда последний параметр функции, её можно вынести за скобки: `applyToAll(numbers) { it + 10 }`.
- Тип `(Int) -> Int`: функция, которая берёт Int и возвращает Int. `() -> Unit`: без параметров и без результата.

## 7. Null safety

- `String`: всегда есть значение. `String?`: может быть `null`.
- `?.`: обратиться, только если не `null` (иначе результат `null`).
- `?:`: запасное значение, если слева `null`.
- `filterNotNull()`: убрать `null` из списка.

```kotlin
println(name?.length ?: 0)
println("Привет, ${name ?: "гость"}!")
```

**Где я ошибался:** `?:` рядом с `+` читается неожиданно, лучше собирать строку шаблоном `"${...}"`.

## 8. Интерфейсы и наследование

- `interface`: контракт «ты умеешь это», без готового кода. Классов-родителей один, интерфейсов можно много.
- `open class`: «ты разновидность этого», потомки получают поля и код родителя.
- Без слова `open` класс и метод в Kotlin закрыты для наследования и переопределения.
- Как выбирать: есть общий код или данные, значит `open class`. Разные по природе классы должны уметь одно и то же, значит интерфейс.

## 9. `enum`, `sealed class` и `when`

- `enum class Direction { UP, DOWN }`: фиксированный набор значений.
- `sealed class`: ограниченный набор вариантов, и у каждого могут быть свои данные (состояния экрана: Loading, Success, Error).
- `when` проверяет все варианты, и компилятор сообщает, если один забыт.
- Для проверки типа варианта используется `is`.

**Где я ошибался:** `println{"текст"}` с фигурными скобками это лямбда, а не текст. Нужно `println("текст")`.
